## Adding screenshots

Open the appropriate bot evidence page, click the pencil icon, and paste a PC screenshot or drag the image file into the editor. Wait for GitHub to finish uploading it, then select **Commit changes**. Copy the saved page URL into the corresponding Discord evidence field.

GitHub supports [attaching files to Markdown](https://github.blog/changelog/2021-03-03-attaching-files-to-markdown-files/) directly in the editor.
